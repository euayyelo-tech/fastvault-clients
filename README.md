# FastVault Clients

This is FSITES LTD's fork of the Bitwarden clients, rebranded and built for
FastVault. See [`fastvault/README.md`](fastvault/README.md) for how the
overlay works and how to build it, and [`README.upstream.md`](README.upstream.md)
